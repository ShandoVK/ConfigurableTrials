 # Configurable Trials

A Risk of Rain 2 mod that allows you to be able to edit the time, starting items, and which trials can appear for the N'kuhana Trials in Hallowed Concepts.

## Known Issues
- Sibylline & Highlander-tier items seem to persist into trials instead of being stored away temporarily at the start unlike all other items.

- None of my methods touch item drops nor items present in an interactable. This makes modded white rarity items pretty much non-existent in trials. Might explore a way to edit these but no guarantee since best action would be to generate this list dynamically.

- Potential multiplayer wonkiness with certain trials like Greed, Scavenger, & Abyss. I tested multiplayer and I noticed no issues due to my mod but do report any issues here if it happens to be because of my mod instead of Gearbox.
