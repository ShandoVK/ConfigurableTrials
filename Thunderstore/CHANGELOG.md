## 0.7.5
- Added different reward modes for items you get for finishing a trial<br>
Changed it as I found the vanilla way to be too deterministic. I changed it to be more alike Void Potentials but this can reverted or set to be completely random, like a chest reward.

- Added ability to give yourself hexes at the start of the trial.<br>
Made this for those that may have found some trials to be a bit too easy and/or want a bit more variety to the trials.

- Removed Glip, you will be missed

## 0.7.1
- Added food tier and Void Lunar tier to the item selector (this tier is from [BubbetsItems](https://thunderstore.io/c/riskofrain2/p/Bubbet/BubbetsItems/))<br>
This is just a safeguard for any other mod that adds food-tier items that doesn't have the CanBeRental tag.

## 0.7.0
- Added ability to edit the starting items given for trials<br>
This feature also supports modded items, some of the configured defaults account for this

- Added support for modded items from your inventory to bring into trials, similar to the vanilla 5 item selector<br>
This is mostly just a bandaid fix until more mods that add items append the CanBeRental tag to itemDef
